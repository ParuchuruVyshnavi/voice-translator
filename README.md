# 🎤 AI Voice Translator

A modern real-time multilingual voice translator web application built using HTML, CSS, and JavaScript.

This application allows users to:
- Speak in one language
- Convert speech to text
- Translate text into another language
- Listen to translated speech
- Save translation history
- Use dark/light themes
- Download translations
- And much more 🚀

---

# 🌟 Features

## 🎙 Voice Recognition
Convert voice input into text using the browser Speech Recognition API.

## 🌍 Real-Time Translation
Translate between multiple languages instantly.

Supported Languages:
- Telugu
- English
- Tamil
- Hindi

## 🔊 Speech Output
Listen to translated text using Speech Synthesis.

## 🌙 Dark / Light Mode
Switch themes dynamically.

## 📜 Translation History
Automatically saves previous translations using localStorage.

## ❤️ Favorite Translations
Save important translations locally.

## 📋 Copy Translation
Copy translated text with one click.

## 📥 Download Translation
Download translated text as `.txt` file.

## 🔄 Swap Languages
Swap source and target languages instantly.

## 🎚 Voice Controls
Adjust:
- Voice Speed
- Voice Pitch
- Volume

## 🎨 Modern UI
Features:
- Glassmorphism design
- Responsive layout
- Voice wave animation
- Smooth hover effects
- Toast notifications

## 📱 Fully Responsive
Works perfectly on:
- Mobile
- Tablet
- Desktop

# 🚀 How To Run

## Method 1 — VS Code Live Server

1. Download project files
2. Open folder in VS Code
3. Install Live Server extension
4. Right click `index.html`
5. Click:
   ```bash
   Open with Live Server
   ```
